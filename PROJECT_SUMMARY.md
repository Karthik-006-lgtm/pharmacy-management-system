## 🚀 HOW TO RUN

### Prerequisites
- JDK 17+
- Maven 3.6+

### Steps
1. Navigate to project directory
```bash
cd "c:\Users\karthik\Downloads\pharmacy system"
```

2. Build the project
```bash
mvn clean package
```

3. Run the application
```bash
mvn spring-boot:run
```

4. Access the application
```
http://localhost:8080
```
